## 你醒来后可以做的

1. **调大云函数超时**：云开发控制台 → 云函数 → `api` → 配置，把超时从默认 3 秒改成 20 秒
2. **上传定时触发器（可选）**：开发者工具里右键 `cloudfunctions/api` → 「上传触发器」，让每天 04:00 自动滚菜单/恢复售罄；不传也不影响使用，打开厨房会自动补跑
3. **确认集合权限**：`categories`、`dishes`、`orders`、`config`、`wishes`、`users`、`coupons`、`menus` 都设为「所有用户不可读写」
4. **真机预览**：在开发者工具点「预览」，用手机微信扫码即可在手机上体验（不需要上传体验版）
5. **订阅消息真机测试**：手机上进入厨房端点「订阅新订单提醒」；用另一个账号下单，看是否收到消息；下单时授权后，出锅时会收到提醒
6. 想正式给女朋友用时，可以上传体验版并把她加为体验成员（你之前说先不上传，这一步留给你）

## 需要留意的限制

- 云开发免费套餐数据库读操作 5 万次/天，按自然日重置；长时间把厨房页挂在前台会消耗读取次数
- 个人主体小程序不能开通微信支付、不能选餐饮类目；对外售卖需要个体户 + 食品经营许可证 + ICP 备案
- 菜品图片存在云存储，删除/替换菜品时会自动清理旧图
- 定时触发器每天 04:00 滚动菜单；即使触发器没生效，管理员每天第一次打开厨房也会自动补跑
