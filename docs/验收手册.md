## 5. 部署之后

1. 在上面的脚本全部通过后再部署 `cloudfunctions/api`
2. 部署成功后至少跑一次 `node scripts/cloud-call.js getWeekMenus '{}'` 和 `node scripts/cloud-call.js getMenuForDate '{"date":"2026-11-05","meal":"lunch"}'`
3. 真机检查一次订阅消息授权与送达（体验版即可，需用户自行上传，当前禁止上传体验版/正式版）
4. 上线前逐项核对 [docs/上线前检查清单.md](上线前检查清单.md)

## 已知限制

- 云开发免费套餐有每日数据库读写额度，额度用尽会报 `EXCEED_REQUEST_LIMIT`，次日 0 点重置。
- 厨房页每 25 秒静默刷新一次订单（只读未完成订单），长时间挂着仍会消耗读取次数。
- 微信侧偶发 `getCloudAPISignedHeader ret:1000 system error`，与代码无关，稍后重试即可。
