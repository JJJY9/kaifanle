- [ ] `miniprogram/config.ts` 的 `CLOUD_ENV` 与正式环境一致，`USE_CLOUD = true`
- [ ] 云函数 `api` 已部署（`cloud functions deploy --env <env> --names api --remote-npm-install`）
- [ ] `cloudfunctions/api/config.json` 的 openapi 权限齐全：
  - `subscribeMessage.send`
  - `security.msgSecCheck`
  - `security.imgSecCheck`
- [ ] 云函数超时时间调到 20 秒（默认 3 秒偏紧，见「已知事项」）
- [ ] 定时触发器 `dailyMenuRoll` 存在（每天 04:00 滚动每日菜单）
- [ ] 首次使用完成 `initDb`，并在 `ADMIN_OPENIDS` 环境变量固定管理员 openid
- [ ] 免费套餐读写额度评估：首页/厨房轮询已降读，但仍需观察单日用量

- [ ] 线上抽查一次晒图审核效果（接口不可用时当前为放行策略）

## 4. 数据与备份

- [ ] `exportData` 全量备份可正常导出（管理员「我的 → 厨房端 → 备份」）

- [ ] 库存变动日志、订单分页、月报等只读接口在正式数据量下不报额度错误
- [ ] 云端验收数据（#001 ~ #004、验收许愿）清理
