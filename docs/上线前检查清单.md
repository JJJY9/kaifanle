> **真机订阅消息 10 分钟验收步骤**
> 1. 版本状态无需配置：代码默认 `MINIPROGRAM_STATE=developer`，开发版预览真机验收即可收到通知。体验版验收时在云开发控制台 → 云函数 api → 配置加环境变量 `MINIPROGRAM_STATE=trial`，发布后改 `formal`（环境变量优先，无需重新部署）。
>   注意：环境变量或在代码默认值下，都需要云函数已完成「含 developer 默认/环境变量支持」的部署（当前线上版本可能仍是旧的 trial 默认，部署成功后本条自动满足）。
> 2. 顾客侧：手机上用微信「扫一扫」或开发者工具「预览」打开小程序 → 下单一次 → 弹出订阅授权时点「允许」。
> 3. 厨房侧：管理员手机同一入口打开 → 厨房端点「订阅新订单提醒」→ 允许。
> 4. 用另一台手机（或同机切账号）再下一单；厨房手机会收到「新订单提醒」，点开应直达订单详情。
> 5. 厨房接单/开火/出锅，顾客手机应收到「订单状态提醒」；点开直达该订单。
> 6. 排查：收不到时先确认第 1 步的环境变量与打开方式匹配（开发版=developer / 体验版=trial / 正式版=formal），再看云函数日志里 subscribeMessage.send 的返回。
